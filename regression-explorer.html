Simple Regression: From the Population to the Sample

ECN 221 Business Statistics · Instructor: Ehsan Asghari-Ghara

1Where the regression line comes from

Simple regression describes how the average of one variable Y changes with another variable X. To see where the line comes from, start with the population. Suppose X and Y together follow a bivariate normal distribution, which is fully described by five numbers: the two means μX, μY, the two standard deviations σX, σY, and the correlation ρ. Its joint density is a hill over the (x, y) plane: round if ρ = 0, stretched into a ridge along a diagonal as ρ moves toward ±1.

Slice the hill at any value X = x. The slice is a normal curve, and its center, the conditional expectation E[Y | X = x], is a straight line in x:

E[Y | X = x] = β₀ + β₁ x,    where   β₁ = ρ · σY / σX   and   β₀ = μY − β₁ μX

This line is the population regression line, also called the conditional expectation function (CEF). Each slice has the same spread around the line, σu = σY √(1 − ρ²), the standard deviation of the error term u = Y − E[Y | X].

In practice we never see the population. We see a sample of n pairs (xi, yi) and fit the sample regression line by ordinary least squares:

b₁ = Σ(xi − x̄)(yi − ȳ) / Σ(xi − x̄)² = r · sy / sx,    b₀ = ȳ − b₁ x̄

Notice that b₁ has exactly the same form as β₁, with the sample correlation and standard deviations standing in for the population ones. Because the sample is random, b₁ and b₀ are random too: a different sample gives a different line.

The key facts about b₁: it is unbiased, E[b₁] = β₁, so across many samples the estimates center on the true slope; and it has a standard error that shrinks with the sample size, SD(b₁) ≈ σu / (σX √n), so the estimates get tighter as n grows, and tighter still when X is spread out or the errors are small. For large n, b₁ is approximately normal, which is what the t tests and confidence intervals for the slope rely on.

4Reading the results

Theory makes two promises about the slope estimate: where its distribution is centered and how wide it is. The simulation checks both.

What the theory predicts

What the simulation produced

Samples drawn0 Average of the b₁ values– SD of the b₁ values– Share of b₁ within ±2 predicted SDs of β₁–

The SD of the collected slopes is the simulation's version of the standard error of b₁.

Three things make the slope estimate precise: a large n, a widely spread X (large σX), and a tight relationship (small σu, i.e. |ρ| close to 1). Changing μX or μY moves the hill around but changes nothing about the slope or its precision.

5Explore further

  1. In panel A, slide ρ from −0.95 to 0.95 and watch the hill and the black line. Then set ρ = 0: the line is flat, but is Y unrelated to X in every sense, or only on average?
  2. Keep ρ = 0.6 and change σY from 1 to 3. The hill stretches vertically and the slope steepens, even though the correlation is unchanged. Why is β₁ not the same thing as ρ?
  3. In panel B, click "Draw a new sample" ten times with n = 50. The population line never moves; the gold line swings around it. Then set n = 10 and repeat. How much wilder are the swings?
  4. In panel C, animate 1,000 samples with n = 50. Is the histogram centered at β₁? Compare the SD of the b₁ values with the predicted SD.
  5. Set n = 200 and rerun. Then set n = 50 but σX = 3. Both tighten the histogram. Which lever is cheaper in practice: collecting four times as many observations, or finding a sample where X varies more?
  6. Set ρ = 0.95 and compare the histogram with ρ = 0.3 (same n). Explain why the slope is estimated more precisely when the points hug the line.
  7. Set ρ = 0 and n = 20, then run 1,000 samples. How often would a researcher looking at a single sample have seen a slope as large as 0.3 or more, even though the true slope is zero? This is why we test H₀: β₁ = 0 instead of trusting the sign of b₁.

Key point: the population regression line is a fixed feature of the population; the sample regression line is a random estimate of it. The estimate is unbiased, so it is right on average, but any single sample's slope can be off by a predictable amount, the standard error. Everything in regression inference, from the standard error printed next to the coefficient to the t statistic and the confidence interval, is a description of the histogram in panel C.
