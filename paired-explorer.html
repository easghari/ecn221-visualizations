Paired vs. Independent Samples

ECN 221 Business Statistics · Instructor: Ehsan Asghari-Ghara

1Two ways to compare "before" and "after", and why one of them is much sharper

Suppose a company measures each of n employees' output before a training program and again after it. There are two ways to test whether training helped:

  1. Independent-samples test. Treat the "before" numbers and the "after" numbers as two separate groups and compare their means, as in the previous chapter: t = (x̄_after − x̄_before) / √(s²_after/n + s²_before/n). This throws away the fact that each before number and each after number belong to the same person.
  2. Paired-samples test. For each employee compute the change d = after − before, then run a one-sample test on the n differences: t = d̄ / (s_d/√n), with n − 1 degrees of freedom.

Why does it matter? Output numbers vary for two very different reasons. First, employees differ from one another: some are fast, some are slow, before and after. Call the size of that spread σperson. Second, the same person's numbers wobble from one measurement to the next, and training helps some people more than others. Call that σnoise. The independent test lumps both together: the person-to-person spread inflates sbefore and safter, so its standard error is large and a modest training effect drowns in it. Taking differences cancels each person's own baseline out, removing σperson entirely. What is left, sd, measures only σnoise, how much the change varies between people, which is usually far smaller. Step 2 spells both quantities out.

The rule: when each observation in one sample is naturally linked to one observation in the other (same person, same store, same matched pair), use the paired test. Pairing does not change the sample means or the estimated effect at all; it changes the standard error, which is what decides whether the effect is detectable.

2How the simulation works

To see why pairing works, we need a population in which we can separate the two reasons that output numbers vary. Every employee's score is built from three pieces:

before = 50 + (person's ability) + (noise)

after  = 50 + (person's ability) + (training effect) + (noise)

  • σperson — person-to-person spread. Employees are not identical: some are naturally fast, some slow. σperson measures how spread out these abilities are across the workforce. A large value means the "before" scores (and the "after" scores) are widely scattered, but it says nothing about the training, because each person's ability is the same in both of their measurements. This is the part pairing cancels: when we compute after − before for one person, their ability appears in both numbers and subtracts out.
  • σnoise — spread in each person's change. Even with no training at all, measuring the same person twice would not give identical numbers (a good day, a bad day, measurement error). And training does not help everyone by exactly the same amount. σnoise measures how much a person's observed change, after − before, varies around the true average effect. This part does not cancel, because it is different in the two measurements. It is the only variation the paired test has to contend with, and sd is its estimate.
  • Training effect. The true average change caused by training. This is what both tests are trying to detect.

The independent test sees the total spread of a before (or after) score, which combines both sources: σgroup = √(σ²person + σ²noise/2). The paired test only sees σnoise. At the default settings, σperson = 15 and σnoise = 4, so a before score has SD ≈ 15.3 but a person's change has SD 4. The paired test's yardstick is almost four times shorter, so the same training effect looks almost four times bigger to it.

With that population in hand we run both tests on the same data, over and over, and count how often each one detects the effect. The text below updates with the settings in step 3.

4Reading the results

The paired standard error depends on σnoise only; the independent one depends on both σperson and σnoise. When people differ a lot from each other (large σperson) but respond to training in a similar way (small σnoise), pairing is a huge win. When σperson is near zero, the two tests are nearly the same, and the paired test even gives up a little because it has only n − 1 degrees of freedom instead of 2n − 2.

5Explore further

  1. Click Run one study a few times with the default settings. Look at the lines: nearly every one slopes upward, yet the before and after clouds overlap heavily. Which test notices the slope, and which only sees the clouds?
  2. Run all 1,000 studies. Compare the two rejection rates. The effect is real, so these are the two tests' power. How many studies did the paired test catch that the independent test missed?
  3. Slide σperson down to 0 and rerun. Now the two tests agree almost perfectly. Why? Slide it to 30: what happens to the independent test?
  4. Set the true effect to 0 (H₀ true). The paired test should reject about 5% of the time. What about the independent test? It rejects far less often than α. Is that "safe", or is it a sign that the test is using the wrong yardstick for these data?
  5. Keep σperson = 15 and ask: how large would n have to be for the independent test to reach the power the paired test has at n = 15? Slide n up until the independent power matches.
  6. Raise σnoise to 15 so that training helps some people a lot and others not at all. Does pairing still help as much? What does sd measure now?

Key point: pairing is a design choice, not a statistical trick. It works because it removes a source of variation that has nothing to do with the question. If the data were collected in pairs, analyzing them as independent groups is not "conservative"; it is simply a weaker analysis of the same information, and it can miss effects that are plainly visible in the data.
